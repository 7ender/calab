# ADR-0008: Права — битмаска роли + overrides по комнате (2026-09-25)

## Решение
11 битов прав (см. `04-data-model.md`), 4 роли workspace с дефолтами, overrides `allow/deny` на комнату для роли или пользователя. Одна чистая функция `computePermissions` в `packages/protocol`, используется сервером (проверка) и клиентом (UI).

## Почему
Модель Discord понятна пользователям, но полная её версия (иерархия ролей, категории, каналы-синки) избыточна. Один уровень overrides покрывает «приватная комната», «только слушать», «нельзя стримить».

## Последствия
- Добавление права = новый бит, без миграции (bigint).
- LiveKit grant вычисляется из тех же битов.
