# ADR-0003: TypeScript везде, pnpm-монорепо (2026-09-25) — ЗАМЕНЁН ADR-0009

> Статус: superseded. Сервер переведён на Go по требованию владельца (минимальная задержка и потребление ресурсов), см. [ADR-0009](0009-go-backend.md).

## Контекст
Сервер можно писать на Go или TypeScript. Клиент в любом случае TypeScript.

## Решение
Node 22 + Fastify + TypeScript на сервере; pnpm workspaces: `apps/desktop`, `apps/server`, `packages/protocol`.

## Почему
- Один язык → общие zod-схемы, типы событий gateway, функция вычисления прав используются и клиентом, и сервером без дублирования.
- Нагрузка MVP (30 пользователей) для Node тривиальна; gateway на `ws` держит десятки тысяч сокетов.
- Экосистема LiveKit server SDK, Drizzle, pino — зрелая.

## Когда пересмотреть
Если gateway/API упрутся в CPU при масштабировании — выносить горячую часть (gateway) в Go, контракт уже формализован в `packages/protocol`.
