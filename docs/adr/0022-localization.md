# ADR-0022: Локализация (ru, en, es, zh-CN) (2026-09-26)

## Контекст
Владелец: перевод приложения и лендинга на английский, испанский и китайский; выбор языка на лендинге и в приложении; автоопределение языка в приложении. Сейчас — один русский словарь (`apps/desktop/src/renderer/i18n/ru*.ts`, типизированный `Dict`), `plural()` только для русского с формами в местах вызова.

## Решение
1. **Словари остаются TS-модулями** (типизация по ключам `ru` как источнику правды): `i18n/<locale>/*.ts` для `ru`, `en`, `es`, `zh-CN`; `t(key, params)`; множественное число — через ключи с формами и `Intl.PluralRules` (категории one/few/many/other), формы в call-sites убираются; даты/время/относительное время — `Intl.DateTimeFormat`/`RelativeTimeFormat` по текущей локали. Ленивая загрузка словаря (dynamic import), переключение без перезагрузки.
2. **Определение языка**: сохранённый выбор → язык ОС (`app.getLocale()` в Electron, `navigator.languages` в вебе) → `ru` для ru/uk/be/kk, `zh-CN` для zh*, `es` для es*, иначе `en` (дефолт для всех неподдерживаемых языков). Выбор — в «Настройки → Основное → Язык» (и на онбординге первым экраном, если язык не выбран явно и ОС ≠ ru).
3. **Лендинг** (Next.js static export): контент по локальным маршрутам `/ru/`, `/en/`, `/es/`, `/zh/`; корень `/` — разводящая страница без контента: скрипт читает сохранённый выбор (localStorage) или `navigator.languages` и делает редирект; если язык не из списка — **`/en/`** (дефолт). `hreflang` + `x-default → /en/`, переключатель языка в шапке (сохраняет выбор). Ссылки из приложения и README ведут на локальные маршруты (`/en/#download`). Старые якоря `/#download` → редирект на `/en/#download` (или сохранённый язык).
4. **Сервер**: строки только кодами ошибок (`code`), тексты — на клиенте; письма/уведомления, если появятся, — по локали пользователя (`users.locale`, v2).
5. **Качество перевода**: первичный перевод — агентом с глоссарием (`docs/i18n-glossary.md`: workspace = пространство/workspace/espacio/工作区, room = комната/room/sala/房间, stream = стрим/screen share/pantalla/屏幕共享, push-to-talk и т.д.); китайский — упрощённый (`zh-CN`); проверка — владельцем/носителями позже; CI-проверка, что у всех локалей одинаковый набор ключей и плейсхолдеров.

## Последствия
- Визуальные эталоны остаются на `ru`; для `en` добавляется по одному снимку главных экранов (`-g "i18n-en"`), остальные локали проверяются проверкой длины строк (переполнение) в unit-тестах.
- README на английском — отдельно (v0.4).
