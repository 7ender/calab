# ADR-0014: Голосовая активация/PTT глушат звук, а не мьютят трек (2026-09-25)

Уточняет ADR-0004 и docs/02 по результатам этапа 3 клиента.

## Контекст
Сервер считает `muted` в voice-state по факту mute микрофонного трека (webhook `track_muted`). Если VAD/PTT закрывают гейт через `track.mute()`, каждая пауза в речи становится событием «выключил микрофон» для всех участников — шум в UI и лишние события.

## Решение
- VAD и PTT в закрытом состоянии подменяют звук тишиной в AudioWorklet (Opus DTX → ~0.1 kbps), трек остаётся опубликованным и не-muted.
- `track.mute()` — только для явного mute пользователем и для deafen.
- Индикатор «говорит» — по `ActiveSpeakersChanged` LiveKit, индикатор «микрофон выключен» — по voice-state.

## Последствия
- Трафик закрытого гейта тот же (DTX), задержка открытия — нулевая.
- Серверная логика voice-state не меняется.
